# 繪畫作品圖片公開策略

> 目的：讓作品能在線上被欣賞，同時降低被拿去印刷、販售、冒用或作其他用途的風險。

## 核心原則

公開圖片無法做到完全禁止下載；只要瀏覽器看得到，就能被保存或截圖。實際策略是：**不公開原始檔、限制公開圖用途、清楚標示權利，並保留足以證明創作的資料。**

## 公開網站放什麼

- 主圖：WebP，長邊上限 1200px，品質約 70–75%。
- 縮圖：WebP，長邊上限 600px，列表頁只載入縮圖，不直接載入主圖。
- 細節圖與過程圖：WebP，長邊上限 1200px，品質約 70–75%。
- 細節圖：只截取需要說明的局部，不提供可還原整件作品的高解析組合。
- 檔名帶作品編號，例如 `BJP-2026-01-cover.webp`。
- 圖片 metadata 可保留作者、版權、網站與作品編號；移除 GPS、設備序號等隱私資訊。

網站不放 TIFF、原始掃描、高解析 JPG、PSD／AI 工作檔或私人收藏證明。也不要上傳原圖後只靠 CSS 縮小，因為瀏覽器仍會取得完整檔案。

## 頁面權利標示

每件作品頁固定放：

```text
© {年份} Fung 蔡承芳 / BianJiaoPie Studio
All rights reserved.

本作品及圖片僅供個人瀏覽。未經書面授權，不得重製、
轉載、修改、用於商品、訓練資料或其他商業用途。
```

公開作品卡只負責介紹作品；含委託人資料、簽名、唯一證書編號或驗證碼的收藏證明，私下交付，不放進公開 repo。

## 私人保存與留證

每件作品的私人資料夾保留：

- 原始掃描與工作檔。
- 草稿、過程照片及完成照。
- 委託溝通與公開姓名的同意紀錄。
- 數位作品卡與私人收藏證明。
- 原始檔 SHA-256 雜湊值。
- 網站首次發布日期與 Git commit。

台灣採創作保護主義，作品完成時即享有著作權，不以登記為必要；上述資料主要用來證明作者、內容與完成時間。

## 不採用的假保護

- 禁止右鍵、透明遮罩：容易繞過，還會傷害操作與無障礙體驗。
- 把圖片切碎：維護成本高，仍可截圖。
- 只靠浮水印：能增加移除成本，但不能阻止盜用；若使用，只放不破壞作品的小型角落署名。
- 只靠 `robots.txt`：只能表達規則，無法強制所有抓取者遵守。

## 〈幸子〉的做法

- 公開頁使用 HTML/CSS，不提供作品卡 PDF 下載。
- 委託人預設顯示「私人委託」，除非取得本人同意才公開名字。
- 補上正式 `cover.webp` 後才把 `cover_ready` 改為 `true`。
- 主圖、文字、手機版及桌面版確認完成後，才把 `published` 改為 `true`。
- 作品受《沉默之丘 f》角色啟發，公開頁不暗示官方合作；若要販售複製品或授權商用，另行確認衍生利用的權利範圍。

## 發布前快速檢查

- [ ] 公開圖不是原始高解析檔。
- [ ] 圖片已移除定位等隱私資訊。
- [ ] 檔名、作品編號與替代文字正確。
- [ ] 頁面有作者及版權聲明。
- [ ] 委託人公開方式已確認。
- [ ] 原始檔、過程資料及證明已私人備份。
- [ ] 沒有 PDF、證書或私人資料被放進公開 repo。
